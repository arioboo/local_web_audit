# Revisión de `.claude/scripts/audit.sh` — 2026-11-15

Proyecto sin git: se revisó el script completo. Hallazgos por orden de gravedad.

1. **Bloqueante — aborta si no hay puertos abiertos** (`.claude/scripts/audit.sh:50`, `:104`)
   `"${OPEN[@]}"` con `set -u` en `/bin/bash` 3.2 (macOS) falla con array vacío (`unbound variable`, rc=127) y no se escribe `report.md`.
   Arreglo: `"${OPEN[@]+"${OPEN[@]}"}"` o guardar con `[ "${#OPEN[@]}" -gt 0 ]`.

2. **`::1` pasa la guarda pero las comprobaciones fallan** (`:13`, `:44-45`, `:59-61`, `:67`, `:74`, `:80`)
   `http://$HOST:$p/` no es válido para IPv6 (`[::1]`); curl devuelve 000. nmap necesita `-6`, openssl necesita corchetes. Falsos negativos silenciosos.
   Arreglo: host entre corchetes para URLs + `-6`, o quitar `::1` de los permitidos.

3. **Métodos con efectos secundarios** (`:66-69`)
   POST/PUT/DELETE/PATCH a `/` de una app real; contradice «solo reconocimiento». Arreglo: solo OPTIONS (`Allow`) y TRACE.

4. **Bajo — `latest` se mueve demasiado pronto** (`:21`)
   Un run abortado deja `latest` sin `report.md`; timestamps de 1 s pueden colisionar.
   Arreglo: actualizar el symlink al final y/o añadir `$$` al timestamp.
